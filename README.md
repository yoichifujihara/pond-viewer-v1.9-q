令和6年能登半島地震の被災地域を対象に、能登全域のため池 1,507 池を検索・選択し、
左右2画面で災害前後の地図を見比べながら、等高線から水位を読み取るためのビューアです。

> **試験運用版です。** URL を知る関係者による限定的な試験運用を想定しています。
> 正式版ではありません。

## v1.9.2-q で変わったところ

解析機能は増やしていません。見え方と操作の改善です。

1. **等高線を細くしました**（これまでの約 60% の線幅）。航空写真を覆いすぎない
   ようにするためです。太い線（計曲線）と細い線の区別、色、間隔はそのままです。
   水位として選んだ線（水色）は読み取りやすさのため太さを変えていません。
2. **ページを読み直さずに 1画面／2画面を切り替え**られるようにし、
   1画面では**スワイプ比較**ができるようにしました（上部バー右端の
   `1画面`・`スワイプ`）。背景・明るさ・等高線・測線の設定は切り替えても
   そのまま残ります。
   - スワイプでは、左画面の地図（**基準**）と右画面の地図（**比較**）を同じ場所・
     同じ縮尺で重ね、境界線の両側に分けて見せます
   - 画面上部の小さなバーで向きを選びます
     - **左右比較**: 縦の境界を左右へ動かします。左が基準、右が比較
     - **上下比較**: 横の境界を上下へ動かします。上が基準、下が比較
   - 境界の白い丸（⇔ / ⇕）をドラッグすると境界が動き、端まで寄せると
     ほぼ全面を片方の地図にできます。向きを切り替えると境界は中央に戻ります

3. **ため池を市町・総貯水量で絞り込める**ようにしました（検索欄の右の `絞り込み`）。
   - 市町は現在の 10 市町から選びます（旧町村の池は所属する市町に含みます）
   - 総貯水量は下限・上限を千m³ で入れます（**下限以上・上限未満**）。
     `〜1`・`1〜10`・`10〜100`・`100〜` のボタンでも選べます
   - 条件は**地図のため池の表示と検索候補の両方**に効きます。検索欄をクリックすると、
     条件に合う池を総貯水量の大きい順に一覧します
   - `該当範囲へ移動` で条件に合う池がすべて入るように地図が動きます。
     `条件をクリア` で元に戻ります。条件は保存しません（読み直すと解除）

4. **開いたときに「このサイトでできること」の案内を出す**ようにしました。
   探す・見比べる・水位を読む・見やすくする の 4 つと、最初に試す一手（「青木作」を検索）を
   1 枚にまとめています。`次回から表示しない` に印を付けると、以後は出ません。
   画面下の青いヒント（「…水位 ？」）を押すと、いつでも開き直せます。

測線は v1.9.1-q と同じです（画面中央の縦・横、`測線: 両方／縦／横／なし`）。
選んだため池のマークは、色だけがオレンジに変わります（大きさは他の池と同じ）。

## v1.9.1-q で変わったところ

解析機能は増やしていません。**航空写真と等高線を見比べやすくするための
操作性の改善だけ**です。

1. **左画面の初期背景をオルソ（電子国土基本図）に**しました。
   左＝通常時のオルソ、右＝災害後の写真、という並びで開きます。
   背景の選択肢は 1 つも減らしていません。
2. **等高線の表示 ON/OFF と、色（標準／白／黒）**を上部バーで選べます。
   暗い航空写真の上では白、明るい地図の上では黒が読みやすくなります。
   OFF にしても水位の読み取りと最近傍検索はそのまま使えます。
3. **診断パネルを既定で折りたたみ**ました。右上の `診断 ✓` を押すと開きます。
   中身は今までどおりです。異常があると `診断 ⚠` に変わります。
4. **左右それぞれ独立した明るさ調整**（0〜500%、既定 100%）を足しました。
   各画面の左下にはじめから開いています。影に入って見えない被災箇所を
   確認するためのものです。効くのは**その画面の地図だけ**で、
   上部バー・ステータスバー・診断・ため池情報・標高ラベルは変わりません。
   `－` で小さくたためます（左右別々）。
5. **右画面に地理院の災害後撮影画像**（2024/1/2・1/5・1/14）を足しました。
   撮影日ごとに複数の地区の画像をまとめて 1 つの背景として扱います。
6. **右画面に、自分で見つけた地図（XYZタイル）を追加できる**ようにしました。
   上部バーの `＋ 外部タイル` から、**地図の名前とタイルURLだけ**で足せます。
   2024年能登半島豪雨の実在する地理院タイルを入力例として入れてあるので、
   使い方はそれを試すのが早いです。

## 使い方

開くと「このサイトでできること」の案内が出ます（画面下の青いヒントからいつでも開けます）。

1. 開くと能登全域が表示されます。青い丸はため池のまとまり（クラスタ）で、
   数字はその中のため池の数です。クリックすると拡大します。
2. 画面上部の検索欄にため池の名前を入れると候補が出ます（例: `青木作` / `杉山ダム`）。
   候補を選ぶと、そのため池まで拡大します。
   `絞り込み` で市町・総貯水量の条件を付けられます（上の「v1.9.2-q で変わったところ」）。
3. 拡大すると等高線が表示されます。**等高線をクリックすると、その標高が
   「水位」として選ばれ**、左右どちらの画面でも同じ高さの線が強調されます。
4. 左右の画面は同じ場所を表示し、**背景地図だけが異なります**。
   画面上部のプルダウンで、左右それぞれの背景地図を切り替えられます。
   右画面では、災害後の**撮影日ごとの航空写真**（2024/1/2・1/5・1/14）も選べます。
5. **等高線** は上部バーの `等高線 ☑` で消せます。隣のプルダウンで色を
   標準／白／黒から選べます。写真が暗いところでは白が読みやすくなります。
6. **明るさ** は各画面の左下のパネルから、左右別々に 0〜500% で変えられます。
   `標準に戻す` で 100% に戻ります。**200〜300% あたりで、影に沈んでいた
   斜面や崩落の跡が見えるようになります。** 左右は完全に独立しているので、
   片方だけ明るくして見比べられます。邪魔なときは `－` でたためます。
7. **診断** は右画面の右上の `診断 ✓` を押すと開きます。開発・確認用の表示です。
8. **1画面・スワイプ** は上部バー右端の `1画面`／`2画面` と `スワイプ` で切り替えます。

### 自分で見つけた地図を右画面に足す

上部バーの `＋ 外部タイル` を押すと、**地図の名前**と**タイルURL**を入れる
画面が出ます。この 2 つだけで右画面に足せます。

はじめての方は、まず入力例を試してください。

1. `＋ 外部タイル` を押す
2. 「入力例：2024年 能登半島豪雨」の **`この例を入力`** を押す
   → 名前と URL が自動で入ります（この時点ではまだ地図に入りません）
3. 中身を確かめて **`追加`** を押す
   → 右画面に「2024能登半島豪雨 9/23 輪島」が出ます
4. 輪島のあたり（例: 37.396, 137.076）へ移動すると写真が見えます

タイルURLは `{z}` `{x}` `{y}` を含む **https** のものだけ使えます
（例: `https://example.jp/{z}/{x}/{y}.png`）。
他の地図を探すときは、ダイアログの中の
「他の地理院タイルを探す」から国土地理院のタイル一覧を開けます。

- 右背景のプルダウンでは、**標準地図**と**ユーザー追加地図**が分けて表示されます
- 追加した設定は**このブラウザの中だけ**に保存されます。サーバへは送りません。
  別のパソコンや別のブラウザには引き継がれません
- 追加した地図の**名前の変更・削除**も同じ画面からできます
- 追加した地図にも明るさ調整・等高線・水位読み取りはそのまま使えます

### 撮影日ごとの航空写真について

日付によって撮影された地区が違います。**その日に撮影されていない場所には
写真が出ません**（背景が無地になります）。異常ではありません。
等高線・ため池・水位は、写真が無い場所でもそのまま使えます。

| 撮影日 | 撮影された地区 |
|---|---|
| 2024/1/2 | 珠洲 / 輪島中 / 輪島東 |
| 2024/1/5 | 珠洲 / 輪島中 / 穴水 / 七尾 |
| 2024/1/14 | 珠洲 / 輪島東 / 穴水 |

### URL パラメータ

| | |
|---|---|
| `?dataset=1m` | 等高線を 1 m 間隔にする（既定は 0.5 m） |
| `?view=single` / `?view=swipe` | 1画面／1画面スワイプで開く（`&swipe=tb` で上下比較） |
| `?panes=1` | 通信量の計測用。右の地図を作らずに開く（スワイプは使えません） |
| `?intro=0` / `?intro=1` | 案内カードを出さない／必ず出す |
| `?zero=1` | 標高 0 m の等高線も描く（既定は非表示） |
| `?worker=0` | 等高線生成の Web Worker を切る（通信を調べるとき用） |

## 技術構成

```text
GitHub Pages
      ↓
静的Webアプリ（サーバ側プログラムなし）

林野庁公式DEM（標高タイル）

等高線はあらかじめ作ったデータではなく、**閲覧のたびにブラウザが標高タイルを
取得し、その場で計算して描いています**。

```

## 外部データの取得先

このアプリは表示のたびに、次の 3 か所からデータを取得します。

| 取得先 | 内容 | 提供 |
|---|---|---|
| `rinya-tiles.geospatial.jp` | **DEM（標高タイル）** — 等高線の元データ | 林野庁 / G空間情報センター |
| `cyberjapandata.gsi.go.jp` | 背景地図（標準地図・オルソ・災害後撮影画像） | 国土地理院 |
| `forestgeo.info` | 背景地図（災害後オルソ・赤色立体図・CS立体図・陰陽図） | 林野庁 |

災害後撮影画像は、地理院タイル一覧の
「令和6年能登半島地震 ◯◯地区 正射画像（2024年◯月◯日撮影）」
10 セットを、撮影日ごとにまとめて表示しています。

**利用者が自分で追加した地図**（`＋ 外部タイル`）を表示している間は、
そのURLの配信元へもブラウザから直接アクセスします。
追加するURLの利用条件は、追加する方でご確認ください。

**DEM 配信元が停止した場合**、等高線と水位読み取りは使えなくなりますが、
背景地図・ため池の表示・検索は使えたままになります。
その場合は画面上に「等高線データを取得できません。」と表示されます。

### 等高線が出ない場所があります

標高データがあるのは **能登半島の陸域だけ**です。海の上や能登の外へ移動すると
等高線は表示されません。これは異常ではないので、警告も出しません
（診断パネルでは「範囲外」として数えています）。

## 出典・利用条件

### 標高データ（等高線の元）

```text
令和6年能登半島地震・DEM/微地形表現図/グラウンドデータ（林野庁加工）
提供      : 林野庁森林整備部計画課全国森林計画班
配信      : G空間情報センター
ライセンス: 政府標準利用規約 / 公共データ利用規約（第1.0版）(PDL1.0)
データセット: https://www.geospatial.jp/ckan/dataset/r6_noto-peninsula-earthquake
```

本アプリは、この標高タイルから**ブラウザ上で等高線を生成する**加工を行っています。
PDL1.0 は加工利用を認めており、出典表示で足ります。

### 背景地図

```text
国土地理院タイル : https://maps.gsi.go.jp/development/ichiran.html
                   （国土地理院コンテンツ利用規約）
林野庁 能登地域2024 : 政府標準利用規約 / PDL1.0
```

### ため池諸元

農業用ため池一覧（`noto_ponds.json`、1,507 池）

## 未確認事項

**恒常的な公開 Web サイトから標高タイル URL を直接参照することと、
そのアクセス量について、配布元へ確認中です。**

データセット本文には「ラスタタイル形式はGIS等でタイルURLを接続することで
ご利用いただけます」と明記されており禁止条項はありませんが、
不特定多数が閲覧する公開サイトに埋め込む場合の記載がないため、
`rinya-opendata@maff.go.jp` へ確認を予定しています。

**この確認が済むまでは、本 URL の広い広報は行いません。**

また、公共測量に用いる場合は別途 国土地理院の成果使用承認が必要です
（データセット本文に明記）。本アプリの用途では該当しない見込みですが、
業務利用の場合は要確認です。

## 動作環境

- Chrome / Edge を推奨します
- 等高線の生成に Web Worker（blob:）を使います。
  組織のセキュリティ設定（CSP）で `worker-src blob:` が禁止されていると
  等高線だけが表示されません
- `file://` では動きません（HTTP/HTTPS 経由で開いてください）
