# ため池災害前後比較ビューア 試行版

**バージョン**: v1.9-q
**位置づけ**: GitHub Pages 試験運用版

| | |
|---|---|
| 公開URL | <https://yoichifujihara.github.io/pond-viewer-v1.9-q/> |
| 旧試行版 | <https://yoichifujihara.github.io/pond-viewer-trial/> |

令和6年能登半島地震の被災地域を対象に、能登全域のため池 1,507 池を検索・選択し、
左右2画面で災害前後の地図を見比べながら、等高線から水位を読み取るためのビューアです。

> **試験運用版です。** URL を知る関係者による限定的な試験運用を想定しています。
> 正式版ではありません。

---

## 使い方

1. 開くと能登全域が表示されます。青い丸はため池のまとまり（クラスタ）で、
   数字はその中のため池の数です。クリックすると拡大します。
2. 画面上部の検索欄にため池の名前を入れると候補が出ます（例: `青木作` / `杉山ダム`）。
   候補を選ぶと、そのため池まで拡大します。
3. 拡大すると等高線が表示されます。**等高線をクリックすると、その標高が
   「水位」として選ばれ**、左右どちらの画面でも同じ高さの線が強調されます。
4. 左右の画面は同じ場所を表示し、**背景地図だけが異なります**。
   画面上部のプルダウンで、左右それぞれの背景地図を切り替えられます。

### URL パラメータ

| | |
|---|---|
| `?dataset=1m` | 等高線を 1 m 間隔にする（既定は 0.5 m） |
| `?panes=1` | 1 画面表示にする |
| `?zero=1` | 標高 0 m の等高線も描く（既定は非表示） |
| `?worker=0` | 等高線生成の Web Worker を切る（通信を調べるとき用） |

## 技術構成

```text
GitHub Pages
      ↓
静的Webアプリ（サーバ側プログラムなし）

林野庁公式DEM（標高タイル）
      ↓
ブラウザ上で動的に等高線を生成
```

等高線はあらかじめ作ったデータではなく、**閲覧のたびにブラウザが標高タイルを
取得し、その場で計算して描いています**。

```text
DEMローカル保存 : なし（0 MB）
PMTiles         : 不使用
Cloudflare R2   : 不使用
```

## 外部データの取得先

このアプリは表示のたびに、次の 3 か所からデータを取得します。

| 取得先 | 内容 | 提供 |
|---|---|---|
| `rinya-tiles.geospatial.jp` | **DEM（標高タイル）** — 等高線の元データ | 林野庁 / G空間情報センター |
| `cyberjapandata.gsi.go.jp` | 背景地図（標準地図・オルソ） | 国土地理院 |
| `forestgeo.info` | 背景地図（災害後オルソ・赤色立体図・CS立体図・陰陽図） | 林野庁 |

**DEM 配信元が停止した場合**、等高線と水位読み取りは使えなくなりますが、
背景地図・ため池の表示・検索は使えたままになります。
その場合は画面上に「等高線データを取得できません。」と表示されます。

## 出典・利用条件

### 標高データ（等高線の元）

```text
令和6年能登半島地震・DEM/微地形表現図/グラウンドデータ（林野庁加工）
提供      : 林野庁森林整備部計画課全国森林計画班
配信      : G空間情報センター
ライセンス: 政府標準利用規約 / 公共データ利用規約（第1.0版）(PDL1.0)
データセット: https://www.geospatial.jp/ckan/dataset/r6_noto-peninsula-earthquake
```

本アプリは、この標高タイルから**ブラウザ上で等高線を生成する**加工を行っています。
PDL1.0 は加工利用を認めており、出典表示で足ります。

### 背景地図

```text
国土地理院タイル : https://maps.gsi.go.jp/development/ichiran.html
                   （国土地理院コンテンツ利用規約）
林野庁 能登地域2024 : 政府標準利用規約 / PDL1.0
```

### ため池諸元

農業用ため池一覧（`noto_ponds.json`、1,507 池）

## 未確認事項

**恒常的な公開 Web サイトから標高タイル URL を直接参照することと、
そのアクセス量について、配布元へ確認中です。**

データセット本文には「ラスタタイル形式はGIS等でタイルURLを接続することで
ご利用いただけます」と明記されており禁止条項はありませんが、
不特定多数が閲覧する公開サイトに埋め込む場合の記載がないため、
`rinya-opendata@maff.go.jp` へ確認を予定しています。

**この確認が済むまでは、本 URL の広い広報は行いません。**

また、公共測量に用いる場合は別途 国土地理院の成果使用承認が必要です
（データセット本文に明記）。本アプリの用途では該当しない見込みですが、
業務利用の場合は要確認です。

## 動作環境

- Chrome / Edge を推奨します
- 等高線の生成に Web Worker（blob:）を使います。
  組織のセキュリティ設定（CSP）で `worker-src blob:` が禁止されていると
  等高線だけが表示されません
- `file://` では動きません（HTTP/HTTPS 経由で開いてください）
